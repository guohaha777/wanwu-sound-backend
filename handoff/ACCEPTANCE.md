# 联调验收：逐项写真实结果

前提：新版前端已部署到已确认 Origin，API 代理返回 JSON；后端维护者已核对管理员／代理并按授权开放测试登录。不要在共享 ECS 做压测。

用受控老师测试账号及合成音频或已有授权示例。不要把密码、Cookie、完整分享令牌、签名 URL 或真实孩子录音写进截图、Issue 和报告。

## 入口与会话

- [ ] `node scripts/probe-deployment.mjs` 通过，前端健康不是 HTML。
- [ ] 邀请码注册、退出、账号密码重新登录；Cookie 是 Secure、HttpOnly、SameSite=Lax、Path=/，无 Domain。不要在报告复制 Cookie 值。
- [ ] 正常页面写请求携带 CSRF，缺少或错误 CSRF／Origin 的请求被拒绝。
- [ ] 改密、一次性密码恢复、停用账号后旧设备会话失效；邀请重复兑换不能创建第二个账号。

## 创作、素材与成品

- [ ] 访客创作不会被登录自动覆盖；主动保存后才迁入账号。
- [ ] 两个草稿、两个设备互不覆盖；同一草稿修订冲突保留本地修改并可另存副本。
- [ ] 录音／文件保留原始 Blob，未上传完成不显示已云端保存；失败不清空创作。
- [ ] WebM、M4A、OGG、MP3、WAV 有实际格式测试；伪造格式、损坏、超过 20 MiB／45.5 秒被拒绝。
- [ ] 技术处理 ready 后仍不自动入库；个人库和共享库分别完成老师试听确认。
- [ ] 正式保存返回异步任务，成品生成后才可播放；长尾未截断，背景关闭、不同乐器和五维组合听感确认。

## 权限与分享

- [ ] 第二位老师不能读取第一位老师的私有作品和素材；伪造资源 ID 不越权。
- [ ] 匿名浏览器可打开已确认发布的作品链接，但拿不到账号、原始录音或私有管理数据。
- [ ] 修改草稿不改变已发布快照；撤销后不再取得新播放授权，等待中的任务不能自动复活分享。
- [ ] 共享素材移除后不再允许新增引用；管理员异常停用音源可撤销相关活动分享。

## 发布前仍需后端维护者完成

- [ ] 当前独立仓库镜像的 Linux 沙箱／资源测试与 Wanwu-only 回滚。
- [ ] 定时加密备份、清理、运维检查实际安装并验证；单次成功不算每天自动执行。
- [ ] 带真实老师数据的独立恢复演练；权限、引用和媒体指纹核对。
- [ ] iOS／Android 麦克风、实际网络中断／签名续期、音乐协作者听感确认。

每项标注 pass／fail／blocked／not-run，写日期、环境和证据位置。不得用本机对象替身、健康接口成功或 GitHub 推送成功替代整条真实链路验收。
