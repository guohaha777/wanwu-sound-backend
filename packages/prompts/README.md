# 语料与提示词 `@wanwu-v2/prompts`

孩子和老师在页面上看到的话（**语料**），以及服务端发给模型的指令（**提示词**），都放在这个包里。和规则包一样，**改文本不改代码**：改完运行 `npm test`，字数超了、用了不该用的词、占位符拼错、少了一项，都会报中文错误并指出是哪一行，不会出现在网页上。

## 谁来决定说什么（2026-10-24 定）

| 方式 | 管什么 | 例子 |
| --- | --- | --- |
| **① 程序直接算** | 所有事实和数字 | 声音体检、五个维度塑形、时长、本地背景、混音、帮我找找、碰一碰、音乐小发现“数出来的事实”、降级链走到哪一步 |
| **② 固定语料**（程序选句、填空） | 操作反馈、对规则做了什么的解释、老师讲解、所有 AI 任务的降级 | 小青蛙 / 小松鼠的台词、声音标记的气泡、灯泡里的老师讲解、本地生成的背景描述 |
| **③ 系统提示词约束的模型**（千问） | 只换说法不加事实；从给定选项里挑；写一句短动机 | 作品讲解、课本讲解润色、心情“自己写”、AI 写音符的动机、课本歌曲的文字（开发期） |
| **④ 模型自由创作** | 只能用描述词引导，事后检查长度和格式 | Fun-Music 生成背景音频 |

一句话：**事实和数字由程序给，孩子操作后的反馈用语料，模型只做“换个说法”和“音乐创作”。**

## 文件

```
corpus/                      语料：网页本地显示，也作提示词里的示例
  style.v1.json              用词规范：每类句子的读者和字数上限、给孩子避开的术语、对谁都不说的话
  sound-hints.v1.json        声音诞生：选完一项后声音标记的联想（按体检分类先说专用的一句，再点一次说下一句）
  discoveries.v1.json        万物成曲：音乐小发现（孩子的一句、老师讲解、可以问孩子、试一试）
  textbook-talk.v1.json      万物成曲：课本讲解四句（特点、这次的样子、碰一碰、试一试）
prompts/                     提示词：只在服务端拼装（前端不打包；提示词台除外）
  system.v1.json             千问各任务共用的系统提示词
  work-talk.v1.json          作品讲解 / 音乐小发现润色 + 一句试一试
  textbook-talk.v1.json      课本讲解润色
  background-notes.v1.json   AI 写音符：一句动机 + 四段疏密和音区 + 低音律动
  background-audio.v1.json   AI 生成背景：Fun-Music 描述词
  mood-words.v1.json         心情“自己写”→ 最接近的预设心情
  sound-hint.v1.json         向导联想（status: closed，现在只用语料）
  textbook-words.v1.json     课本歌曲的心情和一句话（开发期，结果要人耳核对）
src/
  style.ts                   用词检查（语料、动物台词、模型回复共用一套）
  corpus.ts                  读取并检查语料，按事实填空
  accept.ts                  模型回复能不能显示：前端和服务端共用
  tasks/                     拼提示词、读回复、修补（只给服务端和提示词台用）
tests/                       固定样例输入 + 各种模型回复样本
```

占位符写成 `{名字}`，由程序填事实、数字或词表里的词。每个文件可用哪些占位符、词表必须覆盖哪些值，都在 `src/corpus.ts` 和 `src/tasks/*.ts` 里列着，写错会报错。

## 每个 AI 任务

| 任务 | 模型 | 发出去的（匿名） | 拿回来的 | 检查和修补 | 模型不在时 | 页面上的来源 |
| --- | --- | --- | --- | --- | --- | --- |
| 作品讲解 | 千问 | 程序数出的事实，声音只用「声音1」这样的编号；每条附本地说法 | 每条事实一句 + 一句试一试 | 条数、顺序、种类和事实一致；只能提这条事实里的声音；数字必须是事实里的；字数和用词检查。不合格的那一句退回语料 | 语料 `discoveries` | 不标（只记在数据里） |
| 课本讲解润色 | 千问 | 歌曲特征 + 这次的样子 + 碰一碰 + 本地四句 | 同样四句 | feature 里要有歌名；不能加数字；同上。逐句退回 | 语料 `textbook-talk` | 同上 |
| AI 写音符 | 千问 | `BackgroundBrief`（长度、孩子何时在响、速度、拍子、调式、心情、课本节奏特征） | 动机音级和时值、四段、低音律动 | 去掉 Markdown 和多余逗号；取整、截到同样长度、补齐四段；少于 2 个音就不用 | 本地生成的背景 | AI 背景做好后出现“AI”按钮 |
| AI 生成背景 | Fun-Music | 同一个 brief 译成的一段描述 | 音频 | 只能查时长和格式（`parseBackgroundResult`），音量由混音规则压在孩子下面 | 下一步 AI 写音符 | 同上 |
| 心情“自己写” | 千问 | 孩子写的字（服务端审核） | 一个预设心情或 null | 只认 7 种预设 | 如实提示还没开放 | 无（孩子的字原样保留） |
| 向导联想 | 千问 | 维度 + 选项 + 体检分类（不发孩子起的名字） | 一句话 | 字数和用词 | 语料 `sound-hints`（**现在只用语料**：每次点选都请求太慢，也不划算） | 无 |
| 课本歌曲的文字 | 千问（开发期） | 歌名 + 代码算出的数值 + 其他歌已写好的一句话（节奏不同就要说法不同） | 心情 + 一句话 | 只认预设心情，一句话 ≤ 16 字 | 老师或音乐角色手写 | 课本卡片 `extraction.words` |

没有选心情、但选了课本歌曲时，两个 AI 背景都按本地规则的做法，用歌曲的情绪定色彩。

## 用词规范（`corpus/style.v1.json`）

- 每类句子都有读者（孩子 / 老师）和字数上限：联想和动物台词 36 字（孩子起的名字按 4 个字算，气泡里两行以内，手机上也是）、小发现 45 字、试一试 35 字、课本讲解每句 45 字、课本一句话 16 字；老师讲解 80 字、可以问孩子 40 字。页面和弹窗里的提示每条不超过 30 字（`apps/web/tests/wording.test.ts`）。
- 给孩子的话不用这些术语：音域、声部、织体、密度、动态、层次、动机、和声。老师讲解可以用术语，但同一句里要用白话解释。
- 对谁都不说：真棒、好厉害、不对、错了、应该、必须……（不评价孩子）。
- 恰好包含术语的日常词组（例如“柔和声音”里有“和声”）写进 `notTerms`，检查前先去掉。
- `npm test` 用同一套检查扫一遍小青蛙、小松鼠和声音诞生页的所有文字，程序拼出来的句子（选好课本歌曲、背景开、选乐器）用最长的真实组合检查。

## 改语料或提示词的流程

1. 改 `corpus/` 或 `prompts/` 里的文字。
2. 运行 `npm test`：语料覆盖、字数、用词、占位符、词表覆盖、示例回复都会检查。
3. 打开提示词台核对（见下）。
4. **上线前**改文字不升版本号；**上线后**改了提示词就另存新版本文件（如 `work-talk.v2.json`），旧的保留。AI 结果带着它用的提示词版本，作品的 `rendering.prompt` 记录背景用的是哪一版。

## 提示词台 `/lab/prompts`

`npm run dev` 后打开 `http://127.0.0.1:5290/lab/prompts`（和调音台一样，只在开发环境或 `VITE_ENABLE_LAB=1` 的预览构建里有）。选一项任务，看三栏：**程序给模型的匿名摘要**、**模型不在时孩子看到的语料**、**拼好的提示词**（含共用的系统提示词）。下面可以贴一段模型回复（或点“填入示例回复”），页面会显示读取时做了什么修补、哪些句子能用、哪些退回语料，以及最终页面会显示什么。只在本机检查，什么也不发出去。

## 不接模型怎么验收

- `tests/fixtures/briefs.ts`：三个固定的背景请求（平静 + 摇篮曲、热闹没课本、安静没心情），和一组带“像真名字”的声音事实。
- `tests/prompts.test.ts`：每个提示词都填满、不带孩子起的名字和作品编号、长度在预算内；系统提示词带着用词规范；AI 写音符四段计数正确，第二次生成要求换动机。
- `tests/replies.test.ts`：正常回复、带 Markdown、前面多一句话、多余逗号、编了新数字、提到别的声音、用术语、夸孩子、超字数、顺序错、少句、多句、格式完全不对，逐个断言“接受 / 部分接受 / 拒绝”。
- `apps/web/tests/talk.test.ts`：模型关着时什么都不发；太慢或出错算没回答；合格的句子逐句替换语料并换回孩子起的名字。

## 隐私

发给模型的只有匿名摘要：没有录音、照片、地点，也没有孩子起的声音名字（用编号，页面拿回结果后再换回来）。课本歌曲在背景请求里只发特征，不发歌名、音频和旋律；作品讲解和课本讲解润色会带歌名（公开的课本内容），仍不发音频和旋律。密钥和调用只在服务端；页面只能引用 `corpus`、`style`、`accept`，`tests/structure.test.ts` 守着这条边界。
