# 数据契约预留

正式前后端共用的类型、校验与版本信息。工作区包名 `@wanwu-v2/contracts`，按子路径引用，例如 `import {missingProvenance} from '@wanwu-v2/contracts/sound'`。源码直接是 TypeScript，由 Vite 和 Node 测试共同使用。入口弹窗的 typed callback 是 UI 导航意图，不属于这里。

开始真实音源 / 声卡 / 作品功能时，先在此定义并验证契约，再实现本地仓库和远程适配器。页面不得直接依赖数据库结构，也不得把前端权限提示当作服务端授权。

## 已定义

- `src/sound.ts`（`sound-v1`，2026-10-22，声音诞生页；2026-10-24 增加声音体检结果 `SoundAnalysis`（单个声音 `units`、三类 `kind: one | series | texture`、一声的典型长度 `unitMs` / `lengthBand`、高低 `band`，`rules` 记录体检规则版本）与校验 `isSoundAnalysis`；`SoundUnitDraft.analysis` 可选，随声音单元保存，使声场 / 曲谱 / 服务端只凭作品数据就能算出时长）：`SoundSource`（示例 / 本机录音 / 本机文件，带 `provenance`：记录人昵称、日期、大致地点、分组、许可链接；`missingProvenance` 判断能否溯源）、`SoundShape`（高低、长短、变化、轻响、出现方式，取值沿用旧版声卡）、`SoundUnitDraft` 及 `parseSoundUnitDraft` 校验。没有服务端实现；`local-*` 来源表示仅在本机、未上传。`SOUND_SOURCE_MAX_MS` 为 45 秒。以后接存储时按版本迁移，不改已有字段含义。`ShapeInput` 含 `example-preset`（示例声音的预设五项，不是孩子的选择）。2026-10-23 放宽：`SoundUnitDraft.shape` 为 `ChosenShape`（五项都可缺，缺的一项保持原声：原音高、原长度、原音量、只出现一次），`isChosenShape` 校验；尚无任何持久化数据，所以没有升版本号，接存储前如再改需按版本迁移。
- `src/arrangement.ts`（`arrangement-v1`，2026-10-22，万物声场）：`Arrangement`（作品里的声音单元快照、摆放事件、心情、`origin` 示例 / 孩子、`updatedAt`）、`PlacedEvent`（`at` 0–1 先后、`row` 行号只管排版，不存像素，行不改变声音）、`rows`（默认 3，最多 5）、`spanSeconds`（20 / 30 / 45，默认 30，孩子可切换）、`mood`（`MoodChoice`：7 种预设或连接模型后的自己写，原话保留）、每个事件的 `clip`（孩子节选的原声片段，毫秒，只是引用，不剪原件）、`eventsInOrder`、`parseArrangement` 校验（引用、重复 ID、编号唯一、范围、上限）。
- `src/work.ts`（`work-v1`，2026-10-23，万物成曲 / 作品书架）：`ComposeSettings`（背景层开关、乐器列表 `instruments`（只决定用什么乐器演奏生成的背景曲；`[]` = 原始生成的背景声，最多 6 个；只有开关能让背景静音）、音量；课本灵感 `none | textbook | teaching-music`，只借节奏和气质给背景，教学音乐由后台分析后生成背景）、`Visibility`（个人 / 班级 / 学校 / 地区 / 公开，只由服务端决定和执行）、`SavedWork`（ID 与摆放 ID 相同、名字最多 16 字、摆放快照、设置、可见范围、保存时间）、`parseComposeSettings`、`parseSavedWork`、`cleanWorkTitle`。曲谱不存储，总是从摆放派生。
- `src/textbook.ts`（`textbook-v1`，2026-10-24，课本灵感）：`TextbookTrack` 课本歌曲特征模板（速度 `tempoBpm`、拍号 `meter`、节奏型 `rhythmCell`（拍）、疏密、音区 `pitchRange`（MIDI）、明暗、调式、重复、情绪、给孩子的一句话 `childLine`、来源 `source`（示例为 `null`）、提取方式 `extraction`（数值由代码 / 电子谱、文字由 AI / 老师，置信度，是否人耳核对））与校验 `isTextbookTrack`。只存特征和出处，不存歌曲本身；开发期生成，随网页下发，匹配和本地背景都在本机算。
- `src/background.ts`（`background-request-v1`，2026-10-24，万物成曲 AI 背景）：背景来源 `BackgroundSource`（`audio-ai` Fun-Music 音频 / `notes-ai` 千问写音符 / `local-rules` 本地规则）；发给后台的匿名请求 `BackgroundBrief`（长度、孩子的声音何时在响、速度 / 拍子 / 调式 / 心情、摆放的疏密 / 重复 / 高低、课本歌曲的**特征** `TextbookFeatures`（不含歌名、音频和旋律）、选的乐器、规则版本 `RuleVersions`；不含录音、声音名字、记录人、地点）；后台结果 `BackgroundResult`（音频只接受 https、不长于整首；音符逐个校验）与 `isBackgroundBrief` / `parseBackgroundResult`。
- `src/work.ts` 2026-10-24 增加 `SavedWork.rendering`（`Rendering`：孩子留下的背景来源 + 各规则文件版本）与 `isRendering`：浏览器只预览，书架和分享的正式音频由后端按同一版本规则从摆放重新混音。尚无持久化数据，没有升 `work-v1`。
- 2026-10-24：`Inspiration` 的课本选项可带 `variation`（`TextbookVariation`：原样 / 拉长 / 压短 / 错开半拍 / 换到高处 / 换到低处，`textbook.ts`），`BackgroundBrief` 同时带上 `variation`。

- `src/talk.ts`（`talk-v1`，2026-10-24，作品讲解 / 课本讲解）：音乐小发现的事实 `Discovery`（由程序从摆放数出来，原在页面里，现在前后端共用）、碰一碰的种类 `MeetingKind`、讲解来源 `TalkOrigin`（`local` 语料 / `ai` 润色并通过校验）；发给模型的匿名摘要 `WorkTalkBrief`、`TextbookTalkBrief`（声音只用编号「声音1」，不带孩子起的名字，页面拿回结果后再换回名字）与模型回复的形状 `WorkTalkReply`、`TextbookTalk`，校验 `isWorkTalkBrief` / `isTextbookTalkBrief` / `isWorkTalkReply` / `isTextbookTalk`。回复的字数、用词、是否加了事实由 `@wanwu-v2/prompts/accept` 检查。
- 2026-10-24：AI 背景只有一个入口 `POST /api/v1/backgrounds` + `GET /api/v1/backgrounds/{jobId}`（原预留的 `POST /api/v1/works/{workId}/background` 并入）。`BackgroundBrief` 增加 `teachingMusic`（`{musicId}` 或 `null`：老师上传的教学音乐只用上传 ID，不带文件名、音频和旋律；与 `textbook` 不能同时出现），`isBackgroundBrief` 一并校验。请求不持久化，没有升 `background-request-v1`。
- `src/work.ts` 2026-10-24：`Rendering` 增加 `prompt`（AI 背景用的提示词版本，取自结果的 `promptVersion`；本地背景为 `null`）。尚无持久化数据，没有升 `work-v1`。
- 2026-10-24（对齐接口协议 v0.4）：`sound.ts` 的 `SoundSourceKind` 增加 `uploaded`（原件已存到服务端，不可覆盖）与 `SOUND_SOURCE_KINDS`；增加 `SOUND_SOURCE_SLACK_MS`（录到上限时可多出的 500 ms，页面和服务端共用）、来源校验 `isSoundSource`（示例以外最长 45 秒 + 余量），以及音源库条目 `SourceEntry`（`{source, url, analysis}`，`GET /api/v1/sources` 的响应条目；`url` 只接受 https 或本站路径）与 `parseSourceEntry`。`work.ts` 的 `SavedWork` 增加必填的 `share`（`WorkShare`：`pending-review | approved | rejected` + 链接，只有通过审核才有链接；未分享为 `null`；由服务端维护，保存不改它）与 `isWorkShare`，`parseSavedWork` 一并校验。尚无持久化数据，没有升 `sound-v1` / `work-v1`。
